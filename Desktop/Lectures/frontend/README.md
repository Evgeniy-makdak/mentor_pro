# Mentor Pro — Система управления учебным процессом

Модульная веб-система для наставничества и управления учебным процессом. Предназначена для преподавателей (наставников) и студентов.

## 📋 Возможности

### Для наставника:
- Управление дисциплинами, группами, студентами
- Создание лекций и загрузка материалов (PDF, DOC, PPT, изображения, видео, архивы до 500 МБ)
- Создание тестов с вопросами и множественным выбором
- Управление попытками (пересдачи)
- Формирование отчётов по группам и дисциплинам
- Экспорт матрицы успеваемости в CSV
- Просмотр обратной связи от студентов

### Для студента:
- Просмотр лекций и загрузка материалов
- Прохождение тестов с таймером
- Просмотр результатов и оценок
- Отправка обратной связи

## 🚀 Быстрый старт

### Требования

- Node.js 16+
- npm 7+

### 1. Клонирование и установка зависимостей

```bash
# Backend
cd backend
npm install

# Frontend
cd ../frontend
npm install
```

### 2. Настройка окружения (опционально)

Создайте файл `.env` в директории `backend/`:

```env
PORT=3001
JWT_SECRET=your_secret_key_here
DB_PATH=./database.db
```

### 3. Запуск

#### Backend:
```bash
cd backend
npm start
# или
node server.js
```

Сервер запустится на `http://localhost:3001`

#### Frontend:
```bash
cd frontend
npm start
```

Фронтенд запустится на `http://localhost:3000`

### 4. Сборка для продакшена

```bash
cd frontend
npm run build
```

Собранные файлы будут в `frontend/build/`.

## 🔐 Авторизация

### Вход в систему

1. Откройте `http://localhost:3000`
2. Введите логин и пароль
3. После входа система перенаправит на дашборд в зависимости от роли:
   - `mentor` → `/mentor/*`
   - `student` → `/student/*`

### Учётная запись по умолчанию

| Логин | Пароль | Роль |
|-------|--------|------|
| admin | admin | Наставник |

### Токен

- JWT-токен хранится в `localStorage`
- Срок действия: 24 часа
- Автоматически подставляется в заголовок `Authorization: Bearer <token>`
- При истечении токена пользователь перенаправляется на страницу входа

## 📊 База данных

### SQLite

База данных создаётся автоматически при первом запуске сервера в файле `backend/database.db`.

### Схема БД (11 таблиц)

| Таблица | Описание |
|---------|----------|
| `users` | Пользователи (наставники и студенты) |
| `groups` | Учебные группы |
| `disciplines` | Дисциплины |
| `group_disciplines` | Связь групп и дисциплимн |
| `lectures` | Лекции |
| `materials` | Материалы лекций |
| `tests` | Тесты |
| `questions` | Вопросы тестов |
| `answers` | Варианты ответов |
| `user_test_attempts` | Попытки прохождения тестов |
| `user_answers` | Ответы пользователей |
| `feedback` | Обратная связь |

### Настройка БД

Путь к БД задаётся переменной `DB_PATH` (по умолчанию `./database.db` в директории backend).

## 📁 Загрузка файлов

Файлы сохраняются в директорию `uploads/` в корне проекта.

- Максимальный размер файла: 500 МБ
- Максимум файлов за раз: 20
- Поддерживаемые форматы: PDF, DOC, DOCX, PPT, PPTX, ZIP, RAR, JPG, PNG, GIF, MP4, AVI

Файлы доступны по URL: `http://localhost:3001/uploads/<filename>`

## 📖 Использование

### Как наставнику

1. **Войдите** в систему (admin/admin)
2. **Создайте группу**: «Группы» → кнопка «Добавить группу»
3. **Добавьте дисциплину**: «Дисциплины» → «Добавить дисциплину»
4. **Привяжите дисциплину к группе**: через иконку ссылки на дисциплине
5. **Добавьте студентов**: «Студенты» → «Добавить студента» (укажите ФИО, логин, пароль, группу)
6. **Создайте лекцию**: перейдите в дисциплину → «Добавить лекцию»
7. **Загрузите материалы**: нажмите «Загрузить» на лекции
8. **Создайте тест**: «+» на лекции → заполните параметры → добавьте вопросы и ответы
9. **Просматривайте отчёты**: «Отчёты» → выберите группу/дисциплину
10. **Читайте обратную связь**: «Обратная связь»

### Как студенту

1. **Войдите** под своим логином и паролем
2. **Просматривайте лекции** и скачивайте материалы
3. **Проходите тесты** когда они станут доступны (в заданное время)
4. **Смотрите результаты** и оценки
5. **Отправляйте вопросы** через «Обратная связь»

## 📝 Примечания

- База данных использует WAL-режим для лучшей производительности
- Пароли хешируются через bcrypt с salt rounds = 10
- JWT-токен истекает через 24 часа
- При удалении лекции автоматически удаляются все её материалы с диска
- Оценки выставляются по шкале: ≥80% → 5, ≥60% → 4, ≥40% → 3, ≥20% → 2, <20% → 1
- Студенты видят только дисциплины, привязанные к их группе

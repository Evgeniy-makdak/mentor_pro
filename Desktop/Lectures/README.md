# Mentor Pro

Система управления обучением для менторов и студентов.

## Возможности

- 👥 **Управление пользователями**: менторы и студенты
- 📚 **Дисциплины и лекции**: создание и организация учебных материалов
- 📁 **Загрузка файлов**: поддержка различных форматов (PDF, DOC, PPT, ZIP, изображения, видео)
- ✅ **Тестирование**: создание тестов с вопросами и вариантами ответов
- 📊 **Отчётность**: успеваемость студентов по группам и дисциплинам
- 💬 **Обратная связь**: обмен сообщениями между менторами и студентами
- 📱 **PWA**: установка на мобильные устройства, работа офлайн

## Технологии

### Backend
- Node.js + Express
- SQLite (better-sqlite3)
- JWT аутентификация
- Multer (загрузка файлов)

### Frontend
- React
- Ant Design
- React Router

## Установка

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Переменные окружения

Создайте файл `.env` в папке `backend`:

```env
PORT=3001
JWT_SECRET=your_secret_key
DB_PATH=./database.db
```

## PWA (Progressive Web App)

Приложение поддерживает установку на мобильные устройства как нативное приложение:

### Установка на iOS (Safari)
1. Откройте приложение в Safari
2. Нажмите кнопку "Поделиться" (квадрат со стрелкой вверх)
3. Выберите "На экран «Домой»"
4. Подтвердите установку

### Установка на Android (Chrome)
1. Откройте приложение в Chrome
2. Нажмите на меню (три точки)
3. Выберите "Установить приложение" или "Добавить на главный экран"
4. Подтвердите установку

### Преимущества PWA
- 📲 Работа офлайн (кэширование статических ресурсов)
- 🔔 Push-уведомления (готово к подключению)
- 🚀 Быстрая загрузка
- 📱 Адаптивный интерфейс для всех устройств
